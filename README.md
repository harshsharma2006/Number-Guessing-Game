# 🎯 Number Guessing Game (Python)

A simple and interactive command-line Number Guessing Game built using Python.

The computer randomly selects a number between **1 and 100**, and the user tries to guess it.  
The program provides hints whether the guessed number is too high or too low.

---

## 🚀 Features

- Random number generation (1–100)
- Unlimited attempts until correct guess
- Tracks number of attempts
- Input validation with error handling
- Beginner-friendly CLI interface

---

## 🛠 Technologies Used

- Python 3
- random module
- Exception handling (try-except)

---

## 🧠 Concepts Used

- Functions
- While loop
- Conditional statements (if-elif-else)
- Random number generation
- Error handling

## ▶️ How To Run

1. Make sure Python is installed.
2. Clone the repository:

```
git clone https://github.com/harshsharma2006/Number-Guessing-Game.git
```

3. Navigate into the project folder:

```
cd Number-Guessing-Game
```

4. Run the program:

```
python number_guessing_game.py
```
